# MoxSignal Release Repository Rules

1. This repository contains MoxSignal release artifacts and deployment documentation only.
2. MoxSignal source, call specifications, and WebRTC integration design are maintained in the main Mox source repository.
3. Do not add Go source, databases, local caches, real `.env` values, ICE credentials, certificates, or user signaling data.
4. Binary and LPK files must be generated by the main repository release workflow and match the documented version.
5. Deployment documents must not redefine call invitation, signaling, ICE, or SFU contracts.
